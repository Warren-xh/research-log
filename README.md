# 科研日志

每天记录科研进度的个人网站。免费托管在 GitHub Pages，不需要服务器；在任何设备上输入密码就能写日志，保存后网站自动更新。

## 怎么用

- **写日志**：首页点「写今天的日志」。不知道怎么写，就点每一栏上方的提示开个头。
- **发布**：点「发布」，第一次在这台设备上发布时会要你输入密码。网站大约 1 分钟后对所有人更新。
- **草稿**：写的内容自动保存在当前设备，没发布也不会丢。
- **周报**：每周的学到的内容、论文、实验和遗留问题自动汇总成周报，可复制或下载 Markdown。
- **明天的目标**：「明天计划」和没完成的目标，会自动带到第二天的日志里。
- **搜索**：按关键词、标签、项目找历史日志。

每篇日志有这些栏目：一句话总结、项目、标签、投入时长、状态、今日目标、今天学到了什么、做了什么、读的论文/资料、实验记录、卡住的问题、明天计划、自由笔记（支持 Markdown、图片、公式 `$…$`）。

## 密码是怎么工作的

网站本身是静态页面，修改内容需要 GitHub 的写入权限。第一次设置时：

1. 在 GitHub 生成一个**只授权本仓库**的细粒度令牌（fine-grained token，Contents 读写权限）。
2. 在网站「设置 → 第一次设置」粘贴令牌并设一个密码。

令牌在浏览器里用密码加密（PBKDF2 60 万次 + AES-256-GCM），只把加密结果保存为 `data/vault.json`。之后任何设备输入密码，就能在本地解开令牌并直接提交到仓库。

- 密码不会被发送或保存到任何地方。
- 加密文件在公开仓库里，所以密码不要太简单，也不要和其他账号共用。
- 令牌只能改这一个仓库；万一泄露，到 GitHub 删除令牌，再回到网站重新设置即可。
- 令牌最长有效期一年。过期后在「设置 → 修改密码 / 更换令牌」里换新的。

## 数据在哪

| 路径 | 内容 |
| --- | --- |
| `data/entries/YYYY-MM-DD.json` | 每天一篇日志 |
| `data/index.json` | 所有日志的摘要，用于首页、统计和搜索 |
| `data/site.json` | 网站标题、学习计划等设置 |
| `data/vault.json` | 加密后的编辑授权 |
| `uploads/` | 日志里插入的图片 |

每次发布都是一次 Git 提交，误删或改错都能从历史里找回。设置页也可以一键下载全部日志（Markdown 或 JSON）。

## 本地开发

需要 Node.js 18 以上，无任何依赖。

```sh
npm test              # 单元测试
npm run dev           # 预览 http://127.0.0.1:4180
npm run mock          # 带模拟 GitHub 的预览，打开 http://127.0.0.1:4180/?mock
```

模拟模式下可以完整试用设置、发布、删除，所有修改只存在内存里，关掉服务就消失，不会碰到真实仓库。
